# **App Name**: Art Showcase

## Core Features:

- Image Gallery: Display multiple painting images in a gallery format.
- Image Zoom: Enable users to click on an image to view an enlarged version or open it in a modal window.
- Artist Information: Display artist information including name, profile, background, and artistic concept, with a link to other works (if available). Images are stored in the /public/artists directory.
- Responsive Design: Create a simple and clean responsive design that adapts to different screen sizes, ensuring optimal viewing on smartphones and other devices.

## Style Guidelines:

- Use a minimalist color palette with a light or neutral background to make the artwork stand out.
- Implement a subtle accent color (#ADD8E6) to highlight interactive elements and navigation.
- Choose a clean and readable font for all text elements, ensuring readability across all devices.
- Use a grid-based layout for the image gallery to maintain a clean and organized appearance.
- Add subtle transition effects when navigating between images or displaying artist information for a smoother user experience.
